تطبيق طبي ووقائي ذكي لتقييم ومتابعة المؤشرات الحيوية الأساسية للمرضى وكبار السن، وتحليل احتمالات ومخاطر الإصابة بالأمراض المزمنة.

---

### ✨ المميزات الرئيسية (Key Features)
1. **فحص ومراقبة السكري:** تسجيل قراءات السكر الصائم والسكر التراكمي (HbA1c) مع التحليل اللوني الفوري لمستويات الخطورة.
2. **مراقبة ضغط الدم:** قياس الضغط الانقباضي والانبساطي والنبض وتصنيف الحالة (طبيعي، ما قبل الضغط، مرحلة أولى، مرحلة ثانية).
3. **مؤشر كتلة الجسم (BMI):** حساب آلي لمؤشر كتلة الجسم ونسبة الخطر القلبي بناءً على الطول والوزن.
4. **تقييم الكوليسترول والدهون الثلاثية:** حساب نسبة HDL و LDL ومؤشرات الشرايين.
5. **تقرير المخاطر التراكمي والتوصيات الطبية الذكية:** خوارزمية طبية تُحلل القراءات الإجمالية لتقديم تقييم شامل (آمن، متوسط، مرتفع) مع إرشادات غذائية وطبية مخصصة.

---

- **Framework:** Flutter 3.x
- **Language:** Dart
- **Storage & Security:** Secure Local Storage & REST API Client
- **Architecture:** Responsive State Management & Metric Calculators
